# OVERCHARGE ROYALE · 오버차지 로얄

탑다운 배틀로얄 × 말도 안 되는 무기들. 설치 없이 브라우저에서 바로 실행되는 HTML5 게임입니다.

> A top-down battle royale with absurdly overpowered weapons — black-hole cannons, wall-piercing railguns, homing missile swarms and meteor staffs. Pure HTML/JS, no build step. Online multiplayer via Firebase Realtime Database.

**▶ 플레이:** `https://<GitHub 아이디>.github.io/<저장소 이름>/` (아래 "GitHub Pages로 공개하기" 참고)

## 특징

- **배틀로얄 규칙** — 7단계로 줄어드는 자기장, 바닥 전리품, 헬멧·조끼·가방·조준경, 회복템, 2총 + 근접 + 투척 슬롯, 보급 상자
- **무기 28종** — 일반·희귀·영웅·전설·신화 5등급
  - 특이점 캐논(블랙홀), 레일 랜스(벽 관통), 스웜 런처(유도 미사일 6발), 썬더 코일(연쇄 번개), 프리즘 레이저(3갈래)
  - 신화: 아포칼립스 개틀링, 스타폴 셉터(유성 낙하), 가우스 섬멸포, 보이드 사이드
  - 미니 핵, 중력 해머, 플라즈마 카타나 …
- **5200×5200 큰 맵** — 건물 30여 채, 부서지는 나무·바위·상자, 폭발 드럼통
- **비밀 지하 벙커** — 지도 어딘가의 철제 해치 4개. 들어간 사람에게만 보이고, 강한 무기가 숨겨져 있음
- **솔로 · 듀오 · 스쿼드** — 봇 대전(최대 80명)과 온라인 멀티 모두 지원, 팀원 아군 사격 없음
- **무기 시험장** — 모든 무기를 탄약 무한으로 체험
- **코인·스킨 상점** — 배틀로얄 전적으로 코인을 모아 SNS 유행어 테마의 스킨을 구매하고 장착

## 코인과 스킨

봇 배틀로얄과 온라인 배틀로얄에서 두 팀 이상이 참가한 경기의 결과가 나오면 10코인과 처치당 5코인을 받습니다. 승리는 40코인, 2~3위는 20코인, 그 외 상위 절반은 10코인을 추가로 받습니다. 듀오·스쿼드에서는 팀 순위를 적용합니다. 시험장, 관전으로 참가한 경기, 결과가 나오기 전에 나간 경기에는 보상이 없습니다.

로비의 스킨 상점에서 미리 보고 구매하거나 장착할 수 있습니다. 코인, 구매 내역, 장착 정보는 게임을 연 브라우저에 저장됩니다.

배틀로얄에서 1위를 하면 결과 화면에 공용 옷장 접근 카드가 나타납니다. 로비의 **공용 옷장**에서 카드 코드를 입력한 뒤, 구매한 스킨에 이름표를 달아 올리거나 다른 사람이 올린 스킨을 입을 수 있습니다. 옷장에 올린 스킨과 이름표는 Firebase에 저장되어 다른 브라우저에서도 같은 코드로 볼 수 있습니다.

## 실행

빌드가 필요 없습니다. `index.html`을 브라우저로 열거나 로컬 서버로 실행하세요. 추가 무기 효과음은 아래 로컬 서버나 GitHub Pages에서 재생됩니다.

```bash
python3 -m http.server 8811
```

→ http://localhost:8811

`assets/audio/`에는 첨부 효과음 9개를 22.05 kHz 모노 MP3로 압축해 넣었습니다. 여러 무기는 재생 속도와 음높이를 달리해 같은 파일을 사용합니다.

## 온라인 멀티 (Firebase Realtime Database)

로비에서 방 코드를 정해 **온라인 멀티**를 누른 뒤, 방 안에서 **초대 링크 복사**를 눌러 친구에게 보내세요. 링크를 열면 같은 방에 자동으로 접속하고, 방장이 경기를 시작할 수 있습니다. 방 코드를 비워 두면 공개 방 `PUBLIC`에 들어갑니다.

게임은 `js/config.js`에 설정된 Firebase Realtime Database에 바로 접속합니다. 배포된 게임 페이지에서 초대 링크를 복사하면 같은 페이지로 연결됩니다.

### 직접 Firebase 프로젝트를 쓰려면 (포크한 경우)

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트 생성 → 웹 앱 추가 → 설정값을 `js/config.js`의 `firebase`에 붙여넣기
2. 빌드 → **Realtime Database** (Firestore 아님) → 데이터베이스 만들기
3. **규칙** 탭에 [`database.rules.json`](database.rules.json) 내용을 붙여넣고 **게시**
4. **데이터** 탭 맨 위 주소를 `js/config.js`의 `firebase.databaseURL`에 넣기

> ⚠ 이 규칙은 `rooms/` 아래를 누구나 읽고 쓸 수 있게 엽니다 (로그인 없이 바로 하는 캐주얼 게임용). 공개 서비스로 키우려면 Firebase 익명 인증과 더 엄격한 규칙을 붙이는 것을 권장합니다.

### 동기화 방식

- 각자 자기 캐릭터만 계산해 초당 15회 위치를 올리고, 사격은 이벤트로 보내 모두가 같은 결과를 재생합니다.
- 장착한 스킨과 공용 옷장 이름표도 같은 방의 참가자에게 표시됩니다.
- 피해는 맞은 사람의 브라우저가 판정, 아이템 줍기는 트랜잭션으로 먼저 집은 한 명만 가져갑니다.
- 맵·자기장·보급 상자는 경기 시드로 모든 접속자가 똑같이 생성합니다.
- 데이터 위치: `rooms/{방}/presence`, `rooms/{방}/match`, `rooms/{방}/m/{경기}/(p|e|tk|ds)`, `rooms/_wardrobe/skins`

### 같은 컴퓨터에서 멀티 테스트

`index.html?net=local&room=TEST` 를 탭 두 개로 열면 Firebase 없이 탭끼리 대전할 수 있습니다.
